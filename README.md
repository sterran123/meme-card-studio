# 짤·카드 스튜디오

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 파일로 내려받는 순수 브라우저 제작 도구입니다.
로그인 없이 열립니다. 모든 편집은 브라우저 안에서만 일어나고 서버로 아무것도 올라가지 않습니다.

## 사용법

1. **캔버스** — 빈 흰 도화지로 시작. PNG·JPEG를 불러오거나 샘플 배경(밤하늘·노을·민트·종이, 자체 제작) 선택. 드래그로 위치 조정, 줌, **밝기·대비·채도·흐림 보정**, **모서리 배경 자동 제거**.
2. **레이어** — 문구·이미지·도형·그리기 최대 20개. 드래그 이동·회전·불투명도·순서 변경·**핸들 리사이즈**(모서리=비율유지, 변=한 축). **↶/↷ 되돌리기·다시실행 (Ctrl+Z/Y)** 지원.
3. **자유 그리기** — 펜·지우개로 캔버스 위에 직접 그림 (색·굵기 조절, 스트로크 단위 되돌리기).
4. **문구** — 폰트 7종(블랙한산스·주아·프리텐다드·나눔고딕·감자꽃·고운돋움·픽셀), 굵기 3단계·기울기·자간, 채우기는 단색·그라데이션·글리치.
5. **도형** — 사각·원·삼각·별·말풍선·팡파레, 단색/그라데이션 채우기.
6. **스티커** — 입체 일러스트 12종(구름·해·달·산·파도·나무·꽃·별·무지개·풍선·선물, 캔버스 생성 PNG) + 픽셀 14종. 사진형 스티커는 스꾸(`seukku.cc`) 링크에서 골라 개인·비영리 용도로 사용하세요. 복사 후 Ctrl+V로 붙여넣을 수 있고, 클립보드가 막히면 파일로 저장해 사진 레이어로 올리면 됩니다. 외부 파일은 저장소에 포함하지 않습니다.
7. **겹친 이미지** — 사진을 레이어로 올리고 위치·크기·회전·배경 제거 가능. Ctrl+V로 복사한 이미지도 바로 레이어로 추가됩니다.
8. **비율·저장** — 1:1·4:5·9:16, 미리보기와 내려받은 파일은 같은 캔버스 렌더 결과라 항상 일치. PNG/JPG로 내려받기(메타데이터 없이 새 인코딩).
9. **템플릿** — 저장·불러오기·덮어쓰기·삭제 + JSON 내보내기/가져오기 (우리 포맷·단일 템플릿·배열 모두 인식).
10. **테마** — 다크/라이트 전환, 선택이 저장됩니다.

## 파일 형식 정책

- 허용: `image/png`, `image/jpeg` (빈 파일·12MB 초과 거부)
- 거부 시 이유를 토스트로 표시하고 기존 작업은 그대로 유지됩니다.

## 테스트

- 극단 입력 12건 자동 검사 — `checks/` 참고
- PNG·JPEG 업로드 / `.txt` 거부(이유 표시) / 상태 유지
- 템플릿 3개 생성·수정·삭제·새로고침 유지
- 정상·깨진 문법·필수 누락 JSON 세 종류 가져오기 결과
- 완성 이미지 3개 — `checks/final/`

## 실행

정적 사이트입니다. `index.html`을 열거나 로컬 서버로:

```
node tools/serve.mjs   →  http://localhost:8081
```
